# Dark theme screens

HTML source of the 11 dark boards ("The original design in a dark theme") from the Claude Design canvas
"Running Planner iOS": https://claude.ai/code/artifact/aa05df7b-81f3-483b-8fdb-2aa927762da0

They are copies for agents to read (colours, spacing, copy, layout are in the inline styles). They need the
canvas runtime (`support.js`) to render, so open the canvas link to look at them. If the canvas changes,
re-export these files; the canvas is the master.

Reference images for iOS snapshot tests go in `designs/dark/png/` (export each board from the canvas).
